# Privacy Policy

## Data Collection

Digital Doppelgänger is a behavioral analysis research platform. It collects the following data:

### Collected
- **Event types** (click, hover, scroll, key press, page view, etc.)
- **Timestamps** (when events occur)
- **Page identifiers** (which page the event occurred on)
- **Target elements** (which UI element was interacted with)
- **Anonymous session IDs** (UUID, not linked to identity)

### NOT Collected
- Passwords or credentials
- Payment or financial information
- Personal names, emails, or contact information
- IP addresses
- Browser fingerprints
- Exact mouse coordinates (optional and anonymized if captured)
- Personal messages or typed content
- Cookies or tracking identifiers

## Data Storage

All data is stored in a local PostgreSQL database. No data is transmitted to external services.

## Data Retention

Session data persists in the local database for analysis purposes. Users can delete the database at any time.

## Purpose

Data is collected solely for behavioral analysis research — specifically, to demonstrate how automata theory can be applied to distinguish human-like and automated interaction patterns.

## Consent

Users of the Behavioral Playground (DoppelShop) are informed that their interactions generate behavioral events for analysis. No real commerce occurs; the shop is a simulation.
